# ATHENA Engineering Principles

These rules apply to prediction, selection, serialization, export, and
integration work:

1. Never fabricate bookmaker codes or odds.
2. Never force a bet.
3. Unknown data remains unknown.
4. Defaults must be visible.
5. Every probability identifies its method.
6. Every market has one canonical identity.
7. Disabled features remain explicit.
8. Every regression receives a test.
9. Every PR solves one focused problem.
