This records a CI/governance failure and exposed conditional live capability; it does not claim a provider request occurred or retroactively invalidate PR #459's implementation.

Read all workflow runs for that head across event types with pagination, then inspect check-runs, status contexts, review threads, requested reviews, and metadata. Accept a skipped path-filtered surface only when its source guard explains the skip. Pending, unexplained, or failed applicable checks block review readiness.
