# PR #459 direct-share trigger incident correction

This change addresses one governance incident: PR #459 merged while two exact-head, non-skipped direct-share workflows were failed. The failures occurred during pytest collection because those workflows installed `pytest` but omitted `PyYAML`, which the A2 auditor imports from `tests/conftest.py`. Their live create/reload steps were skipped in those runs. That dependency failure was not an operation-authority guard.

Both retained direct-share workflows now run offline validation on matching pull requests. They run a focused deterministic test slice and the source-controlled incident audit. Their `workflow_dispatch` mode is limited to `offline_only`; the explicit event/input guard fails closed for any other value. Neither workflow has a provider HTTP step, a call to the direct-share bridge, an artifact-upload step, a secret binding, or a persisted checkout credential. The direct bridge and its retained research inputs remain unchanged. Any future live proof requires a separate reviewed authority change.

## Historical outcome and exact-head review

PR #459 was reviewed at `c96c74a319d79d2cbc4ed3f8ee2aab9f1b0bd47e` and merged as `7c787130e2662e34813a61422b865046fae52ebd`. Runs `38335345866` (Tests) and `38335345741` (PORT-02C, Linux and Windows) succeeded. The merge-review defect was accepting those two green suites while omitting the two applicable workflow failures. This records a CI/governance failure and exposed conditional live capability; it does not claim a provider request occurred or retroactively invalidate PR #459's implementation.

Before any merge review, pin the PR number, exact head SHA, exact base SHA, open state, and complete commit list. Read all workflow runs for that head across event types with pagination, then inspect check-runs, status contexts, review threads, requested reviews, and metadata. Classify each result as success, pending, failed, timed out, action required, cancelled, neutral, or skipped. Require every mandatory check and every applicable non-skipped workflow to succeed. Accept a skipped path-filtered surface only when its source guard explains the skip. Require Tests syntax, shards 1–8, and aggregate; both direct-share offline validation jobs; and same-head PORT-02C Windows and Linux. Keep historical failures unchanged. Pending, unexplained, or failed applicable checks block review readiness.
